# GDD Space Invaders Project Starter

This is a starting codebase for GDD Project.

## References
This project is based from this 
[Space Invader](https://github.com/janbodnar/Java-Space-Invaders) repository

## GamePlay Instructions 

### Movement 
  - Move with WASD or arrow keys
  - Press space to shoot at enemies

### Rules 
 - get points for killing enemies 
 - Player plane can not hit the boundaries, it will cost a life
 - Two bullets from the enemy plane or from boss cost a life
 - One bullet hit makes shield disappears
 - you can hit enemies with active shield, without using a bullet
